# Reveal.js Premium Presentation Skill

When the user asks for a presentation, pitch deck, keynote, real-estate deck, investment deck, sales presentation or premium animated slides, create a complete Reveal.js HTML presentation.

## Required stack

Use:
- Reveal.js for slides
- Three.js for 3D scenes when useful
- GSAP for cinematic animation
- CSS for premium responsive design

## Visual standard

The presentation must feel expensive, restrained and cinematic.

Inspiration:
- Apple Keynote
- Stripe
- Linear
- Vercel
- OpenAI
- luxury real estate branding

Avoid:
- boring PowerPoint layouts
- generic gradients
- too much text
- childish 3D
- cluttered cards

## Real estate decks

For real estate or cottage village presentations, include:
- premium logo / identity concept
- location story
- masterplan story
- product typologies
- lifestyle narrative
- infrastructure
- investment/commercial logic
- sales strategy
- final emotional closing slide

## Output

Create actual project files:
- index.html
- styles.css
- script.js
- README.md

The result must run in a browser.
