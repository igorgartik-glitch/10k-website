Interaction Playground

Микро-анимации, которые продают детали

Пять паттернов, разобранных покадрово с реального демо-видео компонента и собранных заново на чистом CSS + JS — без библиотек анимации.

Морфинг кнопки: idle → загрузка → успех

Кнопка физически меняет форму (не просто дизейбл), капсула перекрашивается в зелёный, наружу расходится кольцо, вылетают конфетти. Разобрано по кадрам из реального видео-референса.

Магнитная 3D-карточка

Карточка наклоняется вслед за курсором и ловит блик света — ощущение физического объекта, а не плоской картинки.

Подвигай курсором

Карточка наклоняется в 3D и ловит свет вслед за мышью.

Вкладки со скользящим индикатором

Фон-индикатор физически перемещается между вкладками (не просто меняет цвет), контент — кроссфейд.

Дизайн

Индикатор измеряет offsetLeft/offsetWidth активной кнопки и скользит через translateX — не через смену класса на каждой вкладке.

Анимация

380ms, ease-out-expo — достаточно быстро, чтобы не раздражать, и достаточно медленно, чтобы глаз считал движение.

Код

Панели наложены друг на друга через CSS grid (grid-area: 1 / 1), поэтому смена вкладки — кроссфейд без скачка высоты.

Модальное окно со спрингом

Фон плавно размывается, карточка влетает с лёгким перелётом (spring easing), содержимое появляется с небольшим каскадом.

Аккордеон с плавной высотой

Высота анимируется через CSS grid-template-rows (0fr → 1fr) — без JS-измерения scrollHeight и без рывков.

max-height требует угадывать число с запасом и даёт неровный тайминг. grid-template-rows анимирует до реальной высоты содержимого — плавно и без хардкода.

Работает так же — приём не зависит от того, известна ли высота заранее. Браузер сам анимирует до текущего auto-размера.

Да, во всех современных браузерах (Chrome, Firefox, Safari, Edge) — это стандартная возможность CSS Grid.

Плавность по умолчанию

Фон уходит в блюр за 360мс, карточка влетает с лёгким перелётом по spring-кривой, а заголовок/текст/кнопки появляются с небольшим каскадом задержек — не одновременно.
