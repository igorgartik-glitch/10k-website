# ISTRA 52 — премиальная 3D-презентация

Инвестиционная презентация на Reveal.js + Three.js + GSAP: 11 слайдов,
процедурная 3D-сцена посёлка (дома, деревья, вода, дороги, частицы),
камера летит на новую точку при каждом переходе слайда.

Живая версия: https://igorgartik-glitch.github.io/10k-website/istra52/

Все зависимости (Reveal.js, Three.js, GSAP, шрифт Inter) лежат локально в
`vendor/` — открывается без интернета, ничего не подгружается с CDN.

## Как открыть локально

```bash
cd istra52
python3 -m http.server 8000
```

Потом открыть в браузере:

```text
http://localhost:8000
```

Управление: стрелки / клавиши со скроллом, `?print-pdf` в адресной строке —
режим для печати в PDF (Ctrl/Cmd+P → «Сохранить как PDF»).

## Что заменить на реальные данные

- точный адрес участка
- площадь земли
- площадь домов
- цены
- сроки строительства
- реальные рендеры
- генплан
- юридическую структуру сделки
